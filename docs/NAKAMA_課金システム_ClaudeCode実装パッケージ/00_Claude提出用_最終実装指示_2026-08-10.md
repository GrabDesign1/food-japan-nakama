# NAKAMA 最終実装指示（Claude Code提出用）

作成日：2026年8月10日  
優先度：**本書がこのフォルダ内の全ての旧方針・旧フェーズ記載より優先する。矛盾した場合は本書に従う。**

## 今回、実装すること

FOOD JAPAN NAKAMAを、食品の「売りたい」「探している」「共創したい」をつなぐ案件市場として実装する。掲載を有料必須にせず、成果を早めたい事業者が、露出・通知・事務局支援を購入できるモデルにする。

### 基本利用と初回紹介料

| 利用行為 | 今回の仕様 |
|---|---|
| 会員登録・事業者情報登録 | 無料 |
| 「売りたい」「探している」の基本掲載 | 無料 |
| 検索・閲覧 | 無料（ログイン前は概要まで。詳細・連絡は登録後） |
| 買い手から「売りたい」案件への問い合わせ | 無料 |
| 受けた問い合わせへの返信 | 無料 |
| 売り手から「探している」案件への最初の提案メッセージ | 有料 |
| 同一売り手組織・同一買い手組織・同一案件での継続メッセージ | 無料 |

初回紹介料は、通常案件1件1,100円、NAKAMA確認済み優良案件1件3,300円、5件パック4,400円、10件パック7,700円（全て税込）とする。確認済み事業者には組織単位で初回3件を一度だけ付与する。送信後14日間未読の場合のみ、クレジットを1件返還する。開封済みで返信がない場合は返還しない。

月額22,000円（税込）の任意会員プランは残す。通常案件の初回提案30件／月、確認済み優良案件3件／月、掲載オプション20％割引を付与する。未使用枠は翌月へ繰り越さない。既存契約を無断で停止・変更しない。

## 掲載時に実装する有料オプション

案件フォームの公開直前に、次を表示する。

> 基本掲載は無料です。より早く、より多くの相手へ届けたい場合は、有料オプションを追加できます。

まず「おすすめセット」を表示し、その後に「個別にオプションを選ぶ」を置く。分類は「目立たせる」「条件に合う相手へ届ける」「情報を限定する」「NAKAMA事務局へ依頼する」の4つにする。無料で公開申請する導線を隠したり、有料購入を必須にしたりしない。

### おすすめセット

| セット | 料金（税込） | 内容 |
|---|---:|---|
| しっかり告知 | 7日間 8,800円 | 注目表示＋急募ラベル |
| 相手へ届ける | 22,000円 | 注目表示＋条件一致通知100件 |
| 本気で売る | 55,000円 | 最上部PR＋条件一致通知＋SNS紹介申込 |
| 事務局に任せる | 220,000円〜 | 原稿改善＋候補探索＋商談設定（個別契約） |

「広告」「スポンサー」である有料表示は、自然検索とは分離し、必ず広告表記を付ける。条件一致通知は、業種・地域・取扱品目・温度帯・数量・認証等でサーバー側から対象を抽出し、購入前に予定件数を表示する。広告目的のメールは配信同意者だけに送る。

非公開募集は対象外の人に、タイトル・概要・検索結果・OGP・APIから一切漏らさない。応募者限定公開は、承認前に会社名、連絡先、取引条件、資料を出さない。

## サイトに掲載し、相談受付まで今回実装する正式サービス

トップページ、料金ページ、マイページの「事務局へ依頼する」に、以下を表示する。各カードには「相談する」を置き、対象案件・目的・希望時期・予算・連絡先を受け付け、管理画面で対応状況を管理できるようにする。個別契約型の商品は自動決済しない。

| 商品 | 内容 | 料金 |
|---|---|---:|
| NAKAMA登録 | 商品・会社・募集情報の掲載 | 無料 |
| 販促プラン | SNS掲載、クーポン配信、アクセス分析 | 月額33,000円 |
| 販売強化プラン | 特集制作、広告運用、販売企画、月次改善 | 月額110,000円＋広告費 |
| 売れる仕組み構築 | LP、動画、クラウドファンディング、EC、キャンペーン開発 | 100万〜500万円 |
| 販売成果報酬 | NAKAMA経由で確認できる売上 | 売上の10〜20％ |
| 共創・商品開発 | 相手探し、試作、販路、事業化 | 300万〜1,000万円 |

販売成果報酬は、対象商品・販売チャネル・対象期間・NAKAMA経由の認定条件・売上定義・料率・返品取消時の扱い・請求支払時期を個別契約で確定してから開始する。自動請求しない。

## 今回は実装しないこと

- キーワード入札・クリック課金（CPC）
- CPCの最低単価、日額予算、無効クリック除外、請求
- NDA締結ワークフローとNDA後の資料自動開示
- 成果報酬の売上連携・自動請求

これらはUIに「準備中」とも表示せず、後続フェーズで別途承認後に実装する。

## Claude Codeへの作業指示

この依頼では、調査だけで止めず、既存実装を確認後に今回の実装範囲を実装・テストすること。既存仕様と衝突する箇所、または安全に判断できない箇所だけ、コードを変更する前に質問すること。価格・権限・対象者数・公開範囲・初回紹介料の判定は、必ずサーバー側で確定する。Stripeの決済確定は署名検証済みWebhookのみを根拠とする。

完了時には、変更ファイル、DBマイグレーション、テスト結果、未実行項目、本番公開手順、ロールバック手順を報告する。commit、push、deployは行わない。
