# 受入テスト・公開チェックリスト

> 優先順位は `00_Claude提出用_最終実装指示_2026-08-10.md` に従う。本書は受入確認用の補足である。

## A. 無料掲載

- [ ] 有料商品を選ばず「売りたい」を公開申請できる
- [ ] 有料商品を選ばず「探している」を公開申請できる
- [ ] 無料掲載にカード登録を要求しない
- [ ] 有料オプションが成約必須に見えない

## B. 商品・金額

- [ ] 対象案件種別に合う商品だけ表示される
- [ ] 金額、税込表示、期間、審査有無が確認できる
- [ ] ブラウザで金額を改ざんしてもサーバー側価格になる
- [ ] 非公開・停止商品は新規購入できない
- [ ] 過去注文は商品価格変更後も元の金額を保持する

## B-2. 初回紹介料

- [ ] 掲載と閲覧はログイン要件を除き無料である
- [ ] 買い手が「売りたい」案件へ問い合わせるのは無料である
- [ ] 売り手が受信した問い合わせへ返信するのは無料である
- [ ] 売り手が「探している」案件へ新規提案するときだけ料金が表示される
- [ ] 料金、提供内容、返信・成約保証なし、返金条件が購入前に表示される
- [ ] 同じ案件・同じ相手との継続メッセージは無料である
- [ ] 同じ案件・同じ相手へ担当者を変えても二重課金されない
- [ ] 事業者確認後、組織単位で初回無料3件が一度だけ付与される
- [ ] 通常案件1件1,100円で購入・送信できる
- [ ] 確認条件を満たす案件だけ3,300円の確認済み案件になる
- [ ] 5件4,400円、10件7,700円で購入できる
- [ ] パック購入、期限順消費、残高表示が正しい
- [ ] 送信失敗時に予約クレジットが返還される
- [ ] 終了・停止案件には課金されない
- [ ] 返信がないだけでは自動返金されない旨が明示される
- [ ] 送信から14日間未読の場合、クレジットが一度だけ返還される
- [ ] 開封済み・返信なしの場合は自動返還されない
- [ ] 無料クレジットの再登録・別担当者による重複取得を防げる

## C. Stripe

- [ ] Checkout成功後、Webhook前はpaidにならない
- [ ] 正しい署名のWebhookだけ受け付ける
- [ ] 同じイベントを複数回送っても注文・期間が重複しない
- [ ] Checkoutボタン連打で重複注文・二重請求しない
- [ ] 失敗・キャンセル時に有料効果が付かない
- [ ] 返金後に注文状態が同期する
- [ ] 秘密鍵・カード情報・Webhook secretがログに出ない

## D. 掲載効果

- [ ] paidかつ承認済みの商品だけ有効化される
- [ ] 開始前はscheduled、開始後はactiveになる
- [ ] 終了日時後は一覧クエリ上でも無効になる
- [ ] 有料枠に「広告」または「スポンサー」と表示される
- [ ] 自然表示の順位ロジックと有料枠が分離される
- [ ] 急募ラベルの根拠情報を入力できる
- [ ] 同一商品の再購入時の期間加算が正しい

## E. 権限

- [ ] 他人の案件へ有料オプションを購入できない
- [ ] 他人の注文・領収情報を閲覧できない
- [ ] 一般会員が管理操作・返金・期間変更できない
- [ ] 管理操作が監査ログへ残る

## F. 管理・運用

- [ ] 商品価格、期間、公開状態を管理画面で変更できる
- [ ] 注文、決済、審査、掲載状態を別々に確認できる
- [ ] 否認理由、返金状態を記録できる
- [ ] 終了3日前と終了時の通知が一度だけ送られる
- [ ] メール失敗が決済状態を壊さない
- [ ] CSVの文字化け・個人情報過剰出力がない

## F-2. 事務局サービスメニュー

- [ ] トップ、料金ページ、マイページに「事務局へ依頼する」導線がある
- [ ] NAKAMA登録、販促プラン、販売強化プラン、売れる仕組み構築、販売成果報酬、共創・商品開発が正しい料金で表示される
- [ ] 各サービスの「相談する」から、対象案件・目的・希望時期・予算・連絡先を送信できる
- [ ] 相談受付、見積、契約、実施状況を管理者が管理できる
- [ ] 個別契約型サービスで、相談送信だけでは自動決済されない
- [ ] 販売成果報酬に、個別契約で条件確定後に開始する旨が表示される

## G. 後方互換

- [ ] 既存案件の一覧・詳細がエラーにならない
- [ ] 既存月額会員の権限と請求を無断変更しない
- [ ] 既存Webhookが新しいイベント追加後も動く
- [ ] 既存URLとブックマークが維持される

## H. 品質

- [ ] lint成功
- [ ] typecheck成功
- [ ] test成功
- [ ] production build成功
- [ ] モバイル表示確認
- [ ] キーボード操作・ラベル・エラー表示確認
- [ ] Asia/Tokyoの表示日時とUTC保存を確認

- [ ] 掲載開始タイミング
- [ ] 審査基準
- [ ] キャンセル・返金条件
- [ ] 特定商取引法表記
- [ ] 利用規約・広告掲載規約
- [ ] 問い合わせ窓口
- [ ] Stripe本番商品・Price
- [ ] Webhook URLとsecret
- [ ] cron・メール・監視
- [ ] 既存月額22,000円会員の移行方針
- [ ] 初回紹介料とクレジットパック価格
- [ ] クレジット有効期限と失効時の扱い
- [ ] 確認済み優良案件の審査項目・確認有効期間
- [ ] 14日未読返還の公開条件

## J. 公開手順

1. DBバックアップ
2. migration dry-run
3. 本番migration
4. 商品マスター投入（非公開）
5. Stripe本番設定
6. Webhook疎通
7. 管理者だけで購入テスト
8. 掲載開始・終了テスト
9. 商品公開
10. エラー、Webhook、決済、売上を監視

## K. ロールバック

- 商品を非公開にして新規Checkout作成を停止
- 既存paid注文と掲載効果は記録を残したまま管理
- UIの有料導線をfeature flagで停止
- migrationはデータを即時削除せず、旧コードと互換を保つ
- StripeのProduct/Priceを削除せずinactive化
- 返金が必要な対象は注文台帳から個別確認
