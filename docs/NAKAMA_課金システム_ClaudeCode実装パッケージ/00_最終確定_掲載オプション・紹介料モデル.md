# NAKAMA 最終確定：無料掲載＋掲載オプション＋初回紹介料

作成日：2026年8月10日  
優先度：`00_Claude提出用_最終実装指示_2026-08-10.md` に次ぐ補足仕様。本書と同書が矛盾する場合は、同書を優先する。

## 1. 収益構造

NAKAMAは、食品の販売・仕入れ・共創を支える案件市場として実装する。

1. 自分で掲載・検索・応募する基本機能は無料
2. より目立たせる、条件に合う相手へ届ける、情報を限定する機能は有料
3. 事務局が探索・紹介・制作・商談を担う支援は個別の高単価サービス
4. 売り手が「探している」案件へ新規に提案を始める初回メッセージは、紹介料を課金する

| 行為 | 料金 |
|---|---:|
| 会員登録・事業者情報登録 | 無料 |
| 「売りたい」「探している」の基本掲載 | 無料 |
| 検索・一覧・詳細の閲覧（ログイン後） | 無料 |
| 買い手から「売りたい」案件への問い合わせ | 無料 |
| 問い合わせを受けた売り手の返信 | 無料 |
| 売り手から「探している」案件への初回提案 | 紹介料 |
| 同一案件・同一相手との継続メッセージ | 無料 |

ログイン前はタイトル、カテゴリ、地域、概要の一部のみ公開する。詳細条件、資料、相手情報、連絡操作は登録後に開示する。

## 2. 初回紹介料

既存の `00_最終決定_クラウドワークス型メッセージ課金.md` の紹介料仕様を採用する。

- 通常案件：1件 1,100円（税込）
- NAKAMA確認済み優良案件：1件 3,300円（税込）
- 5件パック：4,400円（税込、有効期限180日）
- 10件パック：7,700円（税込、有効期限180日）
- 確認済み事業者への初回登録特典：3件を一度だけ付与
- 課金単位：`売り手組織 × 探している案件 × 掲載者組織` の初回接触1回
- 送信後14日間未読なら紹介クレジットを1件返還。開封済みで返信がない場合は返還しない。

## 3. 掲載時の有料オプション

案件フォーム入力後、公開申請の直前に表示する。無料公開は常に選べる状態にし、有料商品を選ばないことを不利に見せない。

> 基本掲載は無料です。より早く、より多くの相手へ届けたい場合は、有料オプションを追加できます。

選択画面の見出しは、次の4分類とする。

1. 目立たせる
2. 条件に合う相手へ届ける
3. 情報を限定する
4. NAKAMA事務局へ依頼する

## 4. 通知・公開範囲の絶対条件

- 通知は「業種・地域・取扱品目・温度帯・数量・認証等」の条件で対象抽出できること
- 購入前に抽出予定件数を表示し、100件未満であれば実数を明示すること
- メール配信に同意していない会員へ、広告目的のメールを送らないこと
- サイト内通知は通知設定を尊重すること
- 非公開募集は、対象者以外にタイトル・概要・検索インデックス・OGP情報を漏らさないこと
- 応募者限定公開は、承認前には会社名、連絡先、詳細取引条件、添付資料を開示しないこと
- NDA後の資料開示は、NDAの合意記録と資料ダウンロード権限を関連付けること（Phase 2以降）

## 5. 表示・審査・返金

- 有料表示枠には必ず `広告` または `スポンサー` と明記する。自然検索順位には混ぜない。
- 最上部PR、急募、通知、SNS、非公開設定、個別支援は、必要に応じて管理者審査・開始承認を通す。
- 広告商品は成果、問い合わせ、成約、売上を保証しない。
- 決済確定は署名検証済みStripe Webhookのみとし、成功URL到達では有効化しない。
- 審査否認・重複課金・NAKAMA側の未提供は返金または未提供分の返金対象とする。掲載開始後の自己都合取消は原則返金しない。最終文言は法務確認を経て公開する。

## 6. 実装順序

### Phase 1（最初に公開する）

- 基本無料掲載・無料閲覧を維持
- 初回提案の紹介料、クレジット、継続メッセージ無料
- 注目表示、最上部PR、急募表示
- 条件一致通知（メール同意者＋サイト内通知）、対象件数表示
- 非公開募集、応募者限定公開
- おすすめセット、単品選択、Stripe Checkout、Webhook、購入履歴、管理画面

### Phase 2（運用と審査を伴う商品）

- バナー広告の申込・在庫・審査・掲載管理
- 下記「NAKAMAサービスメニュー」の相談・見積・受注管理
- NDA締結後の資料公開
- 反応・配信・クリック計測

### Phase 3（アクセス増加後）

- キーワード・地域・カテゴリ別のCPC入札
- 最低クリック単価50円〜、日額予算1,000円〜、月額上限
- 表示・クリック計測、無効クリック除外、広告ラベル

立ち上げ段階では完全CPCのみにはしない。固定掲載料を中心にし、CPCはPhase 3で追加する。

## 7. 実装禁止事項

- 有料オプション未購入では公開できない設計
- すべてのメッセージを課金する設計
- 買い手からの問い合わせ、またはそれへの返信の課金
- 未同意者への広告メール配信
- 非公開募集・限定公開の情報漏えい
- スポンサー表示の広告表記省略
- フロントエンド送信値だけで金額・対象者数・掲載期間を確定すること

## 8. NAKAMAサービスメニュー（サイトに掲載する正式料金）

掲載オプションとは別に、トップページ、料金ページ、マイページの「事務局へ依頼する」に以下を掲載する。価格はすべて**税込の提案値**であり、個別契約が必要なサービスは「相談する」から事務局が要件確認・見積提示を行う。決済を先に自動実行しない。

| 商品 | 内容 | 料金 |
|---|---|---:|
| NAKAMA登録 | 商品・会社・募集情報の掲載 | 無料 |
| 販促プラン | SNS掲載、クーポン配信、アクセス分析 | 月額33,000円 |
| 販売強化プラン | 特集制作、広告運用、販売企画、月次改善 | 月額110,000円＋広告費 |
| 売れる仕組み構築 | LP、動画、クラウドファンディング、EC、キャンペーン開発 | 100万〜500万円 |
| 販売成果報酬 | NAKAMA経由で確認できる売上 | 売上の10〜20％ |
| 共創・商品開発 | 相手探し、試作、販路、事業化 | 300万〜1,000万円 |

### 8.1 サービスページの表示文言

> 基本掲載は無料です。必要なところだけ、NAKAMA事務局が販促・販売企画・共創事業化まで伴走します。

各有料サービスには `相談する` ボタンを置く。フォームで対象の掲載案件、目的、希望時期、予算、連絡先を取得し、管理画面で相談・提案・見積・契約・実施状況を管理する。

### 8.2 販売成果報酬の必須条件

成果報酬を表示・受注する際は、案件ごとの個別契約で次を確定する。これらが未確定の状態で、売上の10〜20％を自動請求してはならない。

- 対象商品、対象販売チャネル、対象期間
- NAKAMA経由と認定する条件（専用URL、紹介ID、クーポン、紹介先リスト、発注書等）
- 売上の定義（税、送料、値引き、返品、キャンセルの扱い）
- 報酬率、最低報酬、請求・支払時期
- 売上報告の方法と検証資料
- 返品・取消・未回収時の精算、契約終了後の取扱い

Phase 2では、成果報酬案件を `相談受付→見積／契約書→案件登録→月次売上報告→事務局確認→請求` のワークフローで管理する。売上連携が未実装の間は、事業者の月次報告と証憑アップロードを用い、管理者承認後に請求書を発行する。
