# NAKAMA 課金システム Claude Code実装パッケージ

作成日：2026年8月10日  
対象：FOOD JAPAN NAKAMA

## 目的

この一式は、FOOD JAPAN NAKAMAへ掲載時課金・広告課金を実装するため、Claude Codeへ渡す仕様書と実装指示である。

事業上の原則は次のとおり。

> 掲載・閲覧は無料。売り手が「探している」案件へ最初の提案メッセージを送るときは紹介料を支払う。同じ案件・相手との継続メッセージは無料。露出・広告・事務局支援も有料。

通常掲載は無料とし、次の場合に課金する。

- 売り手が「探している」案件へ新規に連絡を開始する
- 掲載を目立たせる
- 条件に合う相手へ届ける
- 広告枠を利用する
- NAKAMA事務局へ制作・探索・商談・販促を依頼する

## ファイル構成

1. `00_Claude提出用_最終実装指示_2026-08-10.md`：今回の実装範囲・料金・優先順位（最優先）
2. `01_課金システム要件定義.md`：サービス、料金、画面、業務ルール
2. `02_技術設計・DB・API・Stripe.md`：実装に必要なデータ・決済・セキュリティ設計
3. `03_ClaudeCode実装指示.md`：リポジトリへ入れて実行する主指示
4. `04_受入テスト・公開チェックリスト.md`：完成判定と本番公開手順
5. `product-catalog.seed.json`：初期商品マスター案
7. `00_最終確定_掲載オプション・紹介料モデル.md`：詳細な業務ルール（補足）

## Claude Codeへの渡し方

このフォルダ一式を対象リポジトリへコピーし、最初に `00_Claude提出用_最終実装指示_2026-08-10.md` と `03_ClaudeCode実装指示.md` を読ませる。

Claude Codeへの最初の依頼：

> `NAKAMA_課金システム_ClaudeCode実装パッケージ/00_Claude提出用_最終実装指示_2026-08-10.md` を最優先で読み、既存システムを確認したうえで、同書にある「今回、実装すること」を実装してください。安全に判断できない競合だけ質問し、それ以外は実装・テストまで進めてください。commit、push、deployは行わないでください。

## 重要事項

- 本書の料金は初期検証案。コードへ直書きせず、管理可能な商品マスターにする。
- 実在企業名を導入実績、候補、広告例として勝手に追加しない。
- 既存の月額22,000円契約がある場合、勝手に解約・返金・停止しない。
- Stripeの秘密鍵、Webhook secret、個人情報をログや画面へ表示しない。
- 本番決済はテスト環境で受入テストが完了するまで有効化しない。
