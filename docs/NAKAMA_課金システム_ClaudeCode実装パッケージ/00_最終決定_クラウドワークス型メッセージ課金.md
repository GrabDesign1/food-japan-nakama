# NAKAMA 最終決定：クラウドワークス型メッセージ課金

作成日：2026年8月10日  
優先度：`00_Claude提出用_最終実装指示_2026-08-10.md` に次ぐ補足仕様。本書と同書が矛盾する場合は、同書を優先する。

## 決定

NAKAMAは、クラウドワークス型の「案件市場＋初回提案課金」で実装する。

| 行為 | 課金 |
|---|---:|
| 会員登録、事業者情報登録 | 無料 |
| 「売りたい」「探している」案件の掲載 | 無料 |
| 案件の検索・閲覧 | 無料 |
| 買い手が「売りたい」案件へ問い合わせる | 無料 |
| 問い合わせを受けた売り手が返信する | 無料 |
| 売り手が「探している」案件へ初めて提案メッセージを送る | 有料 |
| 同じ売り手組織・同じ買い手組織・同じ案件内の継続メッセージ | 無料 |

## 初回提案の紹介料

- 通常案件：1件 1,100円（税込）
- NAKAMA確認済み優良案件：1件 3,300円（税込）
- 5件パック：4,400円（税込、有効期限180日）
- 10件パック：7,700円（税込、有効期限180日）
- 初回登録特典：確認済み事業者・組織単位で3件を一度だけ付与

課金単位は `売り手組織 × 探している案件 × 掲載者組織` の初回接触1回。担当者を替えたり、文章を替えたりしても同じ組み合わせに二重課金しない。

料金は「最初のメッセージ送信と連絡経路の解放」の対価であり、返信・商談・契約・売上は保証しない。送信後14日間、一度も開封されなければ紹介クレジットを1件返還する。開封済みで返信がない場合は返還しない。

## 月額22,000円会員

月額22,000円（税込）は残す。無料登録とは別の任意プランとし、以下の利用枠を毎月付与する。

- 通常案件への初回提案：月30件まで無料
- 確認済み優良案件への初回提案：月3件まで無料
- 上位表示・通知・バナー等の販促オプション：20%割引
- 未使用の月次利用枠は翌月へ繰り越さない
- 人が行う候補探索、紹介、営業、商談設定、企画・制作支援は別料金

月額会員の利用枠を超えた初回提案は、通常会員と同じ紹介クレジット料金を適用する。

## 実装上の絶対条件

1. 初回提案の判定・価格・二重課金防止は、必ずサーバー側で行う。
2. メッセージは、決済確定またはクレジット予約後に送信する。送信失敗ならクレジットを返還する。
3. 買い手から先に届いた問い合わせへの返信に、料金やクレジットを要求しない。
4. 一度解放した案件・相手のスレッドは、追加メッセージごとに課金しない。
5. 「探している」案件には募集期限を必須にし、期限切れ・停止・削除済み案件へ課金させない。
6. 有料オプションと紹介料は、無料掲載・無料閲覧を妨げない。

## 非採用の方針

「登録・掲載・閲覧・応募・問い合わせ・商談をすべて無料にし、初回提案の紹介料を実装しない」という案は採用しない。
