# NAKAMA 課金方針 最終決定書

決定日：2026年8月10日
対象：FOOD JAPAN NAKAMA（https://nakama.food-japan-summit.jp/）
目的：複数の仕様書間で矛盾していた課金方針を一本化し、実装判断のぶれをなくす。

**本書が最優先。本書と矛盾する記載は、日付を問わずすべて無効（停止扱い）とする。**

---

## 1. 確定方針（これだけが有効）

根拠：`NAKAMA_新ビジネスモデル_サイト実装指示書.md`（2026-08-10）＋同日のユーザー最終指示。

### 1-1. 無料で継続利用できる

- アカウント登録・ログイン
- 事業者プロフィールの登録・編集
- 公開案件（売りたい／探している／共創したい）の一覧・詳細閲覧
- 案件の登録・編集・公開
- 案件への応募・問い合わせ
- 基本的なメッセージ（送信・返信とも）
- 自分の案件・応募履歴の確認

無料＝匿名で全機能が使える意味ではない。認証が必要な操作は認証を維持する。
クレジットカード登録は一切不要。

### 1-2. 月額22,000円会員制は新規停止

- 新規申込導線（/billing の申込ボタン、signup→/billing 誘導）をコード上で無効化する
- Stripe の商品・価格・Webhook・環境変数は**削除しない**（復旧可能な状態を保つ）
- 公開画面・メール・SEO・構造化データから「月額22,000円」「月額会員限定」「自動更新・決済」の訴求を削除する
- 既存有料契約＝**1件のみ**（株式会社グラブデザイン。¥0クーポン契約・期間終了時キャンセル予約済み・2026-09-09満了）。実装者判断での解約・返金・停止はしない。9/9の自然満了で解消見込み

### 1-3. 登録時に事業者情報・メールアドレスを取得する

- 登録時にメールアドレス（既存）＋事業者情報（既存プロフィール）を取得
- **案内メールへの同意チェックを新設**：同意した人へ案件・イベント・共創支援等を案内できる（特定電子メール法：事前同意・同意記録・配信停止手段が必要）

### 1-4. 収益は「人が動く」個別支援から得る

サイト内の自動課金商品にはせず、相談後の個別契約・見積とする。

| サービス | 内容 | 表示価格 |
|---|---|---:|
| 共創テーマ設計 | 課題整理、募集条件、企画設計 | 50万円〜（税別） |
| パートナー探索 | 募集設計、候補探索、個別打診、最大5者との面談、実証計画 | 150万円〜（税別） |
| 共創プロジェクト | 募集、選定、商談、試作・実証支援 | 300万円〜（税別） |
| 年間共創プログラム | 複数テーマの探索・実証・事業化支援 | 800万円〜（税別） |
| 制作・販売支援 | Web、デザイン、動画、クラファン、販路等 | 個別見積 |

- 登録者同士の通常取引から売買手数料は取らない（原則）
- 入口は「共創テーマを相談する」専用フォーム（予算帯・公開可否・個人情報同意つき）

### 1-5. 紹介チケット課金は初期公開では入れない（後回し）

初回紹介料・クレジットパック・月30件特典・優良案件3,300円などの**リード課金型の仕組みは、少なくとも初期公開では実装・表示しない**。将来、案件数と利用者が増えた段階で再検討する。

## 3. 実装スコープ（新指示書のPhase構成に準拠）

### Phase 1：課金事故を防ぐ

1. 現行課金の調査（**完了**：契約1件・上記1-2のとおり）
2. 新規月額申込導線の停止（/billing 申込ボタン無効化、signup→/billing誘導の廃止、Paywall誘導の全削除）
3. 既存契約者（自社1件）は9/9満了まで現状維持。Webhookは稼働継続

### Phase 2：無料利用へ権限変更

1. メッセージ送信・返信の PAID ゲート撤廃（sendInterest / sendMessage / startConversation）
2. 台帳公開（togglePublish）・PJ掲載申請（submitProject）・PJ応募（applyToProject）の PAID ゲート撤廃
3. Paywall コンポーネント（UpgradeToMessage / Composer locked）の撤去
4. 管理者限定機能は開放しない。非公開情報の露出がないことを確認

### Phase 3：表側の全面変更

1. トップ：新ファーストビュー（「食の課題を、全国のNAKAMAと事業に変える。」）・CTA=無料で登録する／掲載案件を見る／共創テーマを相談する・2導線・3案件区分・新サービス紹介4種・Summit連動セクション
2. /about：会員制表現→無料登録型へ。「無料でできること」「事務局へ依頼できること」の2列比較
3. /pricing →「利用料金・共創支援」：無料利用0円＋個別支援料金表（1-4）
4. FAQ全面修正（新指示書§6の9問）
5. ヘッダー・フッター・CTA：「NAKAMAに申し込む」→「無料で登録する」等
6. 共創テーマ相談フォーム（新指示書§8。既存 /consultation を拡張：予算帯6択・公開可否・個人情報同意）
7. signup：案内メール同意チェック新設（1-3）
8. SEO・OGP・構造化データ・メール文面から月額表現を削除
9. ログイン前の案件ティザー公開（タイトル・カテゴリ・地域・概要の一部まで。詳細・連絡先・操作はログイン後）

### Phase 4：規約・検証・公開

1. 利用規約・特商法・プライバシーの変更**差分案**を作成（実装者だけで確定しない。公開前に管理者＋必要に応じ弁護士確認）
2. 新指示書§11の全テスト（未ログイン／無料ユーザー／管理者／回帰）
